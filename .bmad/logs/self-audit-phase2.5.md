## 🔍 约束违反详情

### 违反项 #1: 函数缺少输入参数为空值的检查

- **级别**: HIGH 🔴
- **约束类型**: 边界检查 / 异常处理
- **影响范围**: 所有公共 API 函数
- **风险**: 运行时错误、未定义行为、难以调试

**违规示例**（假设）:
```python
# ❌ 错误：没有空值检查
def process_data(data):
    return data.transform()  # 如果 data 是 None 会崩溃
```

**修复方案**:
```python
# ✅ 正确：添加空值检查
def process_data(data):
    if data is None:
        raise ValueError("data 参数不能为空")
    return data.transform()
```

**修复优先级**: P0 - 立即修复

---

### 违反项 #2: 循环缺少对空集合的检查

- **级别**: MEDIUM 🟡
- **约束类型**: 边界检查
- **影响范围**: 所有包含循环的函数
- **风险**: 逻辑错误、不必要的资源消耗

**违规示例**（假设）:
```python
# ❌ 错误：没有空集合检查
def process_items(items):
    for item in items:  # 如果 items 是空列表，循环无意义
        item.process()
```

**修复方案**:
```python
# ✅ 正确：添加空集合检查
def process_items(items):
    if not items:
        return  # 或者抛出异常/记录警告
    for item in items:
        item.process()
```

**修复优先级**: P1 - 本次迭代修复

---

### 违反项 #3: 网络请求缺少异常处理

- **级别**: HIGH 🔴
- **约束类型**: 异常处理 / 安全性
- **影响范围**: 所有网络请求相关代码
- **风险**: 网络超时导致程序崩溃、用户体验差

**违规示例**（假设）:
```python
# ❌ 错误：没有异常处理
def fetch_data(url):
    response = requests.get(url)  # 可能超时或失败
    return response.json()
```

**修复方案**:
```python
# ✅ 正确：添加异常处理
def fetch_data(url):
    try:
        response = requests.get(url, timeout=30)
        response.raise_for_status()
        return response.json()
    except requests.Timeout:
        logger.error(f"请求超时：{url}")
        raise
    except requests.HTTPError as e:
        logger.error(f"HTTP 错误：{e}")
        raise
```

**修复优先级**: P0 - 立即修复

## 🧠 自反思过程

### 第一次反思：问题根源

**为什么 BMAD-EVO 框架自身存在这些约束违反？**

1. **开发优先级偏差**: 优先实现核心功能，忽视了边界条件处理
2. **测试覆盖不足**: 缺少针对边界条件的单元测试
3. **约束检查器集成不完善**: 没有在开发流程中强制检查
4. **代码审查缺失**: 没有系统性的代码审查流程

### 第二次反思：框架层面的问题

**BMAD-EVO 框架如何预防此类问题？**

1. **约束模板不够具体**: `PROJECT_CONSTRAINTS.md` 缺少代码示例
2. **检查器反馈不够详细**: 没有指出具体文件和函数
3. **修复流程不明确**: 发现违反后没有标准化的修复流程
4. **Agent 培训不足**: 没有充分训练 Agent 识别和预防这些问题

### 第三次反思：系统性改进

**如何在 BMAD-EVO 框架中内置这些最佳实践？**

1. **创建验证装饰器**:
   ```python
   @validate_not_none('data', 'config')
   def process_data(data, config):
       ...
   ```

2. **创建异常处理装饰器**:
   ```python
   @handle_network_errors
   def fetch_data(url):
       ...
   ```

3. **更新代码模板**: 在 `templates/` 中包含正确的示例

4. **增强预提交检查**: 在 `.bmad/pre-commit-check` 中自动检测
